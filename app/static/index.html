docreader-ocr извлекает структурированные данные из фотографий российских документов: находит документы на снимке, определяет их тип, детектирует поля и распознаёт текст. Всё локально, без внешних API.

example.py
from docreader import DocReader

result = DocReader().process("passport.jpg")

for doc in result.documents:
    print(doc.doc_type, doc.fields)

Архитектура

Трёхуровневый ИИ-конвейер

Каждый компонент заменяем: свой классификатор, детектор или OCR-движок передаются в DocReader(...).

  1. 1

    Классификатор

    YOLO11n-obb

    Находит все документы на фото, определяет тип и вырезает повёрнутый (OBB) кроп каждого.

    97.5% accuracy

  2. 1a

    Resolver

    YOLO + EasyOCR + rapidfuzz

    Аттестат и диплом визуально почти одинаковы — их различает текст поля «уровень образования».

    только для attestat/diplom

  3. 2

    Детектор полей

    YOLO11n-obb × 4

    Отдельная модель на каждый тип документа находит 6–10 полей: ФИО, даты, номера, кем выдан.

    90.0% mAP@50

  4. 3

    OCR

    EasyOCR · VGG–BiLSTM–CTC

    Дообучен на 11 752 примерах полей российских документов: кириллица, латиница, цифры.

    87.3% word accuracy

Почему OBB, а не обычные рамки?

Документы на фото повёрнуты. Повёрнутая рамка точнее обтягивает поле, и кроп для OCR чище: IoU вырос с ~0.78 до 0.96.

Почему EasyOCR?

После дообучения EasyOCR показал 87.3% word accuracy против ~79% у PaddleOCR, и его проще конфигурировать.

Почему CTC Loss?

Не нужно посимвольное выравнивание: для обучения достаточно строки целиком, длина текста может быть любой.

Интеграция

Три строки кода, и система работает

Настройка
from docreader import DocReader, PipelineConfig

config = PipelineConfig(
    device="cuda",
    classifier_confidence=0.3,
    detector_confidence=0.25,
    enable_deskew=True,
)

with DocReader(config) as reader:
    page = reader.process("scan.jpg")
    print(page.to_dict())
