# Демо-сайт docreader-ocr

Сайт с живой демонстрацией библиотеки [docreader-ocr](https://pypi.org/project/docreader-ocr/):
загружаете фото документа и видите каждый этап пайплайна.

## Что показывает демо

- найденные документы на исходном фото (OBB-рамки классификатора);
- тип документа, уверенность и диагностику resolver для аттестата и диплома;
- поля на кропе документа: подсветка рамки при наведении на строку и наоборот;
- распознанный текст и уверенность OCR по каждому полю, пометку «проверить» при уверенности ниже 60%;
- редактирование полей, как при проверке оператором; правки сразу попадают в JSON;
- время каждого этапа: классификация, resolver, детекция, OCR;
- JSON в формате `PageResult.to_dict()` и Python-код с текущими параметрами.

Ниже на странице идут архитектура, метрики, интеграция и команда (по материалам презентации).

## Запуск

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Или просто `run.bat`. Затем откройте http://127.0.0.1:8000.

При первом запуске библиотека скачивает веса (~125 МБ) в `~/.cache/docreader/models/`.
На CPU обработка одного документа занимает от 1 до 30 секунд.

## Примеры для демонстрации

Положите фотографии в `app/static/samples/`: они появятся в блоке «Примеры» под зоной загрузки
и будут открываться одним кликом. Не публикуйте фото с реальными персональными данными.

## Структура

```
app/
  main.py          FastAPI: /api/recognize, /api/status, /api/samples
  static/
    index.html     страница
    styles.css     стили (светлая и тёмная темы)
    app.js         логика демо
    samples/       ваши примеры фото
```

Загруженные фото обрабатываются в памяти и не сохраняются на диск.
